# mcmere Play 0.1.2

サーバー指定のリソースパックを、MODと一緒に準備できるようになりました。

- 「準備して参加」で必要なZIPを同期し、リソースパックを有効化して指定の優先順位へ揃えます。
- 「構成」タブにパックと優先順位を表示します。必須パックは保持し、推奨パックは選択できます。
- 音量・キー割当・画面設定・セーブを保持し、パック選択に必要な項目だけを更新します。
- 同期中断時の復旧、同一ZIPのハッシュ検証、配布形式1との互換性に対応します。
- 0.1.1の個人追加MODを保持する動作を引き継ぎます。

既存のPlayでは「アプリ設定」→「更新を確認」から更新できます。更新情報は既存のアプリ更新鍵で署名しています。Setupの取得後、PrismとMinecraftを閉じて更新してください。

Windows x64向けのプレビュー版です。Setup自体にはAuthenticode署名がありません。更新manifestの署名とファイルのハッシュを検証します。

標準build、個人MOD保持・パック同期・個人設定保持・中断復旧のテスト、ブラウザーとWebView2での配布連携を確認しました。個別パックのゲーム内表示や互換性は管理者による確認が必要です。
