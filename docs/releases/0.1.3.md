# mcmere Play 0.1.3

自動適用したリソースパックがNeoForgeのMODリソースより低い優先順位になる問題を修正しました。

- 初回準備でも、サーバー指定のリソースパックがMODのアセットを上書きする順序で有効になります。
- 既存環境は、更新後に「環境を確認」から準備するか、「設定」→「確認して修復」を実行すると選択順を修復できます。手動でZIPを入れ直す必要はありません。
- リソースパックの自動ダウンロード・更新・ハッシュ検証、個人MOD・音量・キー割当・セーブの保持を継続します。

既存のPlayでは「アプリ設定」→「更新を確認」から更新できます。PrismとMinecraftを閉じて更新してください。更新情報は既存のアプリ更新鍵で署名しています。

全123テストとUI・Desktop・Setupの標準ビルドを確認しました。Minecraft 1.21.1 / NeoForge 21.1.250の実クラスと合成リソースによる検証では、修正後の自動適用と手動選択のロード順・アセットの採用元が一致しました。

Cobblemon / Mega ShowdownとATM x MSDを組み合わせたGengar・Luxray・Luxioの実ゲームでの戦闘・描画確認は未実施です。この更新はロード優先順位の修正であり、個別パックのすべてのクラッシュ解消を確認したものではありません。

Windows x64向けのプレビュー版です。Setup自体にはAuthenticode署名がありません。更新manifestの署名とファイルのハッシュを検証します。
