# mcmere Play 0.1.1

個人で追加したMODを保持したまま参加できるようになりました。

- `mods`へ自分で追加した地図・レシピ表示などのMODが、配布対象外であることだけを理由に退避を求められる問題を修正しました。配布MODの更新・修復でも個人追加MODを保持します。
- 「MOD」画面に個人追加MODの一覧と更新ボタンを追加しました。追加MODを外して確認したい場合だけ、一覧から一括退避できます。
- 配布側が管理するMODの更新・修復、起動前の配布版確認は継続します。

## 更新方法

「アプリ設定」→「更新を確認」から更新を準備し、PrismとMinecraftを終了して適用してください。Setupによる上書き更新もできます。設定とゲームデータは保持されます。

旧版で退避済みのMODは自動で戻しません。必要なJARをデータ保存先の `backups/<インスタンスID>/<更新ID>/game/mods/` からゲームの `mods` へコピーしてください。バックアップが整理済みの場合は配布元から再取得してください。

## 検証と制限

同期・中断復旧を含む106件の.NETテストと、個人追加MODがある状態での参加・修復・任意退避のUIテストを実施しました。

個人追加MODの互換性は自動判定しません。Minecraftとローダーに対応する版を使用し、配布MODと同じMODの別バージョンを重複させないでください。実際の地図MOD・JEIを入れたMinecraft起動とサーバー接続は今回の自動テストに含みません。

Windows x64向けのプレビュー版です。EXEにはコード署名がありません。アプリ更新情報には既存の公開鍵で検証できる署名を付けています。
