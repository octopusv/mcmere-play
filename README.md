# mcmere Play

**サーバーに合う環境を、準備して参加。**

遊びたいMinecraftサーバーに合わせて、Java・NeoForge・MODの環境を準備するWindowsアプリです。必要なファイルやバージョンを確認し、サーバー専用のフォルダーに揃えます。

**[Windows用Setupをダウンロード（v0.1.1）](https://github.com/octopusv/mcmere-play/releases/download/v0.1.1/mcmere-play-Setup-0.1.1.exe)** · [リリース一覧](https://github.com/octopusv/mcmere-play/releases)

現在は初回プレビュー版です。通常は上のSetupを1つダウンロードして使ってください。ZIP版はリリース一覧から取得できます。

個人の検証用には、証明書の登録・削除batを含む[自己署名テスト版](docs/SELF_SIGNED_TEST.md)も用意しています。Smart App Controlへの対応を保証するものではありません。

## 用意するもの

- **Windows 10 / 11の64bit（x64）PC**
- **Minecraft: Java Editionを遊べるMicrosoftアカウント**と、自分のMinecraft名
- サーバー管理者から案内された**配布ページのURL**と、ホワイトリストへの登録
- インターネット接続と、ゲーム・MODを保存する空き容量

GoogleログインやPlay用のアカウント登録はありません。ゲーム用のMicrosoftログインは、起動用アプリの**Prism Launcher**で行います。必要なJavaとPrismは、Playの「準備して参加」から導入できます。

## はじめて参加する

### 1. mcmere Playをインストールする

1. 上のリンクから`mcmere-play-Setup-0.1.1.exe`をダウンロードして起動します。
2. 保存先を確認して**「インストール」**を押します。保存先は初期設定のままで使えます。
3. 完了したら**「mcmere Playを開く」**を押します。次回からはWindowsのスタートメニューで「mcmere Play」を検索して開けます。

WebView2 Runtimeの導入が表示された場合は、Setupの案内に従ってください。現行プレビュー版のEXEにはコード署名がなく、Windowsの確認画面が出る場合があります。ダウンロード元がこのリポジトリのReleaseであることを確認してください。

### 2. サーバーを追加して、自分の名前を入力する

1. 管理者から届いた配布ページをブラウザーで開き、**「アプリで開く」**を押します。
2. Playで**「サーバーを確認」**を押し、表示されたサーバー名と配布元を確認して**「このサーバーを追加」**を押します。
3. **「名前を入力」**から自分のMinecraft名を入力し、**「名前を確認する」**を押します。Microsoftアカウントのメールアドレスではなく、ゲーム内で使う名前を入力します。

ブラウザーからアプリが開かない場合は、Playの**「サーバーを追加」**を押し、「配布ページのURL」へ管理者から届いたURLを貼り付けてください。

名前を確認できない場合は、入力を見直し、サーバー管理者にホワイトリストへの登録を確認してください。

### 3. 環境を準備して、Prismから起動する

1. **「準備して参加」**を押し、Java・Prism・MODの準備が終わるまで待ちます。初回はダウンロードに時間がかかります。
2. Prismが開いたら、初回設定の案内を進め、Minecraft: Java Editionを遊べるMicrosoftアカウントにログインします。
3. Prismで対象サーバーのインスタンスを起動し、Minecraft・NeoForgeの初回取得を完了します。インスタンスは、そのサーバー専用のプレイ環境です。

Playから起動すると接続先もPrismへ渡されます。ゲームがタイトル画面で止まった場合は、「マルチプレイ」から管理者に案内されたサーバーへ接続してください。

**Prismが見つからないときは、Playで対象サーバーを選び、「設定」タブ →「Prismを開く」を押してください。** このボタンはPrismの準備が終わると使えるようになります。

## 次回から遊ぶ・更新する

Playを開いてサーバーを選び、画面に**「環境を確認」**が出ていれば押します。確認が終わったら**「参加する」**から起動します。

MODなどの更新がある場合は**「準備して参加」**で必要な差分を取得します。「Prismで起動」が表示された場合は、Prismの初回設定やログインを完了してください。ファイルの更新時にPrismやMinecraftの終了を求められたら、両方を閉じて再試行します。

Play本体の更新は、左下の**「アプリ設定」→「更新を確認」**から行えます。画面に従って更新を準備し、PrismとMinecraftの終了後に適用してください。

## MOD・保存先・データについて

「構成」タブではMODとリソースパックを確認できます。配布形式2のパックは「準備して参加」でファイルと有効化・優先順位を揃えます。必須パックは外せません。音量・キー割当等は保持し、`options.txt`のパック選択項目だけを更新します。壊れた設定や中断後の競合を検出した場合は上書きを保留します。

| やりたいこと | 操作・動作 |
|---|---|
| MODの一覧を見る | 対象サーバーの「MOD」タブを開きます。参加に必須のMODは外せません。選択可能なMODだけ有効・無効を変更できます。 |
| 自分用のMODを追加する | 「設定」→「フォルダーを開く」から`mods`へJARを追加します。配布対象外のMODは更新・修復時も保持され、そのまま「参加する」で起動できます。「MOD」タブの「一覧を更新」で確認できます。 |
| ゲーム用メモリを変更する | 対象サーバーの「設定」タブで変更します。最初はサーバーの推奨値で使ってください。 |
| ゲームのフォルダーを開く | 対象サーバーの「設定」タブ →「フォルダーを開く」。 |
| 保存ドライブを変える | 「アプリ設定」→「保存先を変更」。PrismとMinecraftを閉じてから実行します。移行後はPrismへの再ログインが必要です。 |
| サーバーの登録を外す | 対象サーバーの「設定」タブ →「登録を外す」。ゲームデータは残ります。 |
| Playをアンインストールする | Windowsの「インストールされているアプリ」から削除します。ゲームデータは既定で残り、データ削除を選んだ場合だけセーブなども削除します。 |

Playは専用のフォルダーとサーバーごとの環境を使います。既存のMinecraft環境や個人のセーブを上書きしません。Play専用の環境でも、ゲームの個人設定とセーブを保持しながらMODを更新します。管理者が配布対象にした設定ファイルは、サーバーの指定に従って更新されます。

保存先の移行では、コピーと確認が終わってから新しい保存先へ切り替えます。元のデータも残ります。

個人で追加するMODは、Minecraftとローダーに対応するものを選び、配布MODと同じMODの別バージョンを重ねて入れないでください。個人追加MODの互換性はPlayでは確認しません。配布側が管理するファイルは指定版へ更新・修復されます。

追加MODを外して確認したいときだけ、「MOD」→「追加MODの退避を確認」から一括退避できます。旧版ですでに退避されたJARは自動復元しません。必要なファイルをデータ保存先の`backups/<インスタンスID>/<更新ID>/game/mods/`からゲームの`mods`へコピーしてください。バックアップは更新に伴って整理されるため、残っている世代を確認してください。

## 困ったとき

| 表示・状況 | 対処 |
|---|---|
| 「ホワイトリストで名前を確認できません」 | 自分のMinecraft名を確認し、管理者に登録状況を確認してください。名前を変更した場合も再確認が必要です。 |
| 「サーバーは停止中です」 | サーバーの起動を待ちます。環境の準備だけ先に進められる場合は「環境を準備」を押してください。 |
| 「配布内容の確認を待っています」／構成の対応を確認できない | 管理者に表示内容を伝えてください。サーバー側の更新・起動・配布設定の確認が必要です。 |
| 「更新する前にPrismを閉じてください」 | PrismとMinecraftを終了して「再試行」を押します。 |
| 「手動で取得するファイルがあります」 | 「MOD」タブの「配布ページを開く」から取得し、「ファイルを取り込む」でダウンロードしたファイルを選びます。その後、再試行してください。 |
| 「追加したMODが見つかりました」で参加できない | Playをv0.1.1以降へ更新してください。個人追加MODを保持して参加できます。 |
| ダウンロードが失敗した／ファイルが壊れた | 通信と空き容量を確認し、対象サーバーの「設定」→「確認して修復」を試してください。 |
| 「保存済みの設定を復元」が表示された | そのボタンから前回の設定への復元を試せます。ゲームデータは保持します。復元できない場合は管理者へ相談してください。 |

解決しないときは、表示されたメッセージとPlayのバージョンを管理者へ伝えてください。**「アプリ設定」→「診断ログ」の「保存する」**から診断ZIPを保存できます。診断ZIPは自動送信されません。

名前の照合は配布を利用するための確認で、Minecraftアカウントの本人認証ではありません。ゲームへの参加には、Prismでのログインとサーバー側の参加許可が必要です。
